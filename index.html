How a call gets to you.

A hardened edge in front of a fully private core — and a control plane that decides the route of every call, live.

  1. 01

    Filtered at the edge

    Hostile traffic — floods, banned sources, out-of-policy origins — is dropped silently before it ever reaches your PBX.

  2. 02

    Media anchored

    Voice streams terminate at the edge proxy. Internal topology stays hidden, and the PBX is never exposed to the internet.

  3. 03

    Routed in real time

    The control plane classifies every call as it arrives — tenant, number, destination — and dispatches it over the PBX’s control API.

  4. 04

    Delivered

    Calls land in a queue with the right ring strategy, an agent’s line, an auto attendant, a conference room, or voicemail.

Questions, answered.

Is this SaaS?

No. Sirius Telefonix deploys on your own Kubernetes infrastructure — your calls, recordings, CRM data, and AI voicemail summaries never route through our systems. The demo runs on a guided environment we host for evaluations only.

How many concurrent calls can it handle, and what hardware do we need?

The platform is lab-tested to 1,000 concurrent calls with continuous two-way G.711 RTP media using kernel-space media forwarding (xt_RTPENGINE) and a split two-node topology. We provide measured per-pod CPU and memory sizing profiles for 100, 200, 500, 800, and 1,000 concurrent calls — starting from a single 8-vCPU / 16 GiB worker node for 100–200 calls up to two 16-vCPU worker nodes for 1,000 calls.

What is it built on?

A proven open-source telephony core — Asterisk 22, OpenSIPS 3.6, RTPEngine with kernel forwarding, PostgreSQL 17, and Garage S3-compatible storage — paired with a Java control plane and dedicated ARI call router, an Angular admin console and agent/supervisor desk, a Rust audio transcoding service, and optional on-cluster Whisper + Gemma voicemail AI. Everything is driven through a REST API with OpenAPI documentation.

How do we evaluate it?

Request a demo. You’ll get a guided walkthrough of a live environment — queues, the supervisor wallboard and WFM, the agent desk with its browser phone and CRM workspace, and enterprise security controls — in about 30 minutes. If it fits, the next step is a pilot deployment on your infrastructure.
